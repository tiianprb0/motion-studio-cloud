# Lembar ide episode

Arahan pengguna 7 Nov 2026 ("1-13 jalankan"), diadaptasi dari pola lembar ide di buku gaya Republik Netizenia.

- **Kapan:** diisi **sebelum menulis naskah**.
- **Di mana:** salin ke `projects/<slug>/v1/01-Brief/LEMBAR-IDE.md`. Lembar ini isi cerita proyek, jadi memang tempatnya di folder proyek. Template ini tetap di `references/`.
- **Kapan siap:** kalau semua baris terisi, naskah bisa ditulis dan dicek dengan `pola-naskah.md` (atau `pola-standup.md` untuk Open Mic).
- **Yang tidak dipakai:** baris yang tidak relevan ditulis "—" disertai alasan singkat. Jangan dihapus.

## Template

| Baris | Isi |
|---|---|
| Judul episode | |
| Seri dan narator | Less. reguler (Naya/Yan), Open Mic (Yan), atau Lirik (Naya/Yan, tanpa narasi) |
| Asal ide | pengalaman, isu, atau komentar (kalau dari komentar: izin komentator, lihat pola-standup bagian 10) |
| Situasi akrab (1 kalimat) | |
| Penilaian/asumsi yang dipertanyakan | |
| Rumus hook + kalimat hook (0–3 dtk) | lihat pola-naskah "Hook 0–3 detik"; tanpa salam, shot pertama sedang/close-up |
| Kata kunci pencarian (1) | kata yang diketik orang di pencarian; muncul di hook, subtitle, caption, judul |
| Varian naskah | A "Tapi ternyata" / B "Cerita lalu mundur" / C "Dua sisi" / Open Mic |
| Belokan "Tapi…" | kalimat + detik target (±55–65% durasi) + perubahan visual |
| Alasan dan bukti | contoh, riset, data, beserta sumber; tandai fakta/dugaan/opini |
| Momen "oh ternyata" | konteks mengejutkan di belokan; emosi kagum/terkejut, bukan marah/cemas |
| Dikirim ke siapa? | satu orang yang paling mungkin dikirimi video ini |
| Penutup | pertanyaan atau pengamatan yang tertinggal, bukan moral |
| CTA Outro C | `ikuti` / `tanya` (pertanyaan tentang penonton, jawab 1–3 kata) / `seri` + teksnya / `titip` (ajakan ke less.benaya.id) / `dari` (wajib untuk video dari keresahan web; nama hanya kalau boleh disebut) |
| Callback kucing | shot, posisi, dan pose kucing oranye di latar (duduk/tidur/jalan; tidak dijelaskan) |
| Tokoh dan lokasi | |
| Target durasi dan kata | reguler 61–75 dtk (±145–175 kata), Open Mic < 90 dtk, Lirik mengikuti potongan lagu |
| Judul sampul (2–4 kata) | lihat references/thumbnails.md |
| Caption dan komentar sematan | lihat references/kemasan.md |
| Khusus Open Mic | nomor episode, premis, bit 1–3, punchline terkuat, callback penutup, uji tunjuk (pola-standup 3a) |
| Khusus seri Lirik | lagu + penyanyi; potongan (m:ss–m:ss di lagu, bagian apa); makna tiap baris dengan kata sendiri (jangan salin lirik; rujuk nomor baris); nomor baris yang ditonjolkan sebagai teks + gayanya; konteks yang tidak dinyanyikan; kalimat caption + kredit. Baris naskah (kata kunci di narasi, varian, belokan, bukti) diisi "—". |

## Contoh terisi: Maaf yang Nggak Pernah Diucapin v2

Diisi ulang dari video yang sudah jadi (7 Nov 2026), untuk patokan kepadatan. Tanda ⚠ menunjukkan bagian yang tidak memenuhi aturan baru.

| Baris | Isi |
|---|---|
| Judul episode | Maaf yang Nggak Pernah Diucapin (v2) |
| Seri dan narator | Less. reguler, Naya (Leya) |
| Asal ide | Narasi dari pengguna (7 Nov 2026) |
| Situasi akrab | Habis bertengkar, pacar tidak pernah bilang "maaf", tapi besoknya tiba-tiba perhatian. |
| Penilaian yang dipertanyakan | "Dia cuma gengsi." |
| Kata kunci pencarian | (kalau dibuat ulang) "minta maaf": muncul di narasi ("nggak pernah bilang maaf") dan bisa ditaruh di caption |
| Hook | Pengakuan "aku": "Pacarku punya satu kebiasaan yang dulu selalu bikin aku kesal." (0,5–5,1 dtk; kalimatnya agak panjang untuk 3 detik). ⚠ Audit pembuka: narasi mulai 0,52 dtk, subtitle belum tampil di 0,3 dtk, shot lebar (skala 2,0). |
| Varian naskah | B "Cerita lalu mundur" |
| Belokan "Tapi…" | Konteks: "Sampai aku tahu, di rumahnya dulu, nggak ada yang terbiasa minta maaf." (24,8 dtk = 33%). Pemahaman baru: "Akhirnya aku ngerti…" (42,7 dtk = 56%) ✓. Visual: kilas balik rumah masa kecil, lalu balkon senja. |
| Alasan dan bukti | Kilas balik keluarga (martabak setelah bapak marah), ditandai "mungkin" (dugaan). ⚠ Belum ada bukti di luar cerita, misalnya riset bahasa kasih atau cara keluarga berdamai. |
| Momen "oh ternyata" | "Di rumahnya dulu, nggak ada yang terbiasa minta maaf": martabak sebagai cara berdamai ✓ |
| Dikirim ke siapa? | Pasangan yang jarang bilang maaf, atau sahabat yang punya pacar seperti itu |
| Penutup | "Dan mungkin, dari situ dia mulai belajar, kalau kata maaf juga boleh diucapin." (pengamatan) |
| CTA Outro C | (kalau dibuat ulang) `tanya`: "Kamu tipe yang bilang, atau yang nunjukin?" |
| Callback kucing | ⚠ Belum ada. Kucing hitam di jalan senja (baris 14) adalah kucing lokasi lama, bukan kucing callback oranye. |
| Tokoh dan lokasi | Naya, Yan, keluarga Yan (kilas balik). Warung tenda, gerbang dan tangga kos, rumah masa kecil, gerobak martabak, balkon senja, bangku taman, jalan senja. |
| Target durasi dan kata | 138 kata, 75,7 dtk. ⚠ Sedikit di atas 75 dtk (ekor Outro B 5 dtk; dengan Outro C jadi ±73,7 dtk) |
| Judul sampul | "Dia nggak bilang maaf." (label HUBUNGAN, gaya "wajah + latar lokasi"; `04-Hasil/Thumbnail-Maaf.png`) |
| Caption dan komentar sematan | (kalau dibuat ulang) lihat contoh di references/kemasan.md |
