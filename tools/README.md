# Alat bersama Motion Studio

Semua alat produksi ada di sini, bukan di folder proyek. Folder proyek hanya berisi naskah, audio, timeline, `src/Film.tsx` (aksi, kamera, timing cerita itu) dan hasil. Kalau sebuah proyek butuh alat atau komponen yang bisa dipakai konten lain, buat atau perbaiki di `tools/` atau `shared/`, lalu impor dari sana.

Jalankan dari root workspace. Node: `.toolchain/node/bin/node`. Dependensi JS ada di `tools/node_modules` (tidak masuk git; pulihkan dengan `cd tools && npm install`, versi dipin di `tools/package.json`). Lokasi ffmpeg, Chrome, dan Playwright dicari oleh `runtime.cjs` / `runtime.py`.

## Daftar alat
| Alat | Fungsi |
|---|---|
| `render-film.cjs` | Render, stills, proof, kunci versi, dan audit (anatomi, skala efektif ≤4,6 setelah zoom kamera, safe area subtitle/popup, subtitle ≤7 kata dan ≤2 baris, jarak gelembung–subtitle ≥100 px, shot ≥1,3 dtk, pose dikarang, impor dari proyek lain/arsip, file umum di folder proyek). |
| `render-film.cjs --motion` | Persen waktu diam per shot (metode sama dengan perbandingan Kok Bisa?: 26–38% diam). |
| `render-film.cjs --sfx` | Daftar efek suara otomatis dari `data-sfx` komponen shared. |
| `audit-overlay.cjs` | Isi pemeriksaan audit (termasuk bubble ≤4 kata). Setelah mengubahnya, jalankan `node tools/test-audit.cjs`. |
| `test-audit.cjs` | Contoh yang sengaja salah; semuanya harus tertangkap. |
| `captions.cjs` | Ukur kata (Lato Bold 44px) dan pecah subtitle: maks 7 kata, 2 baris seimbang, utamakan batas kalimat/tanda baca. |
| `narration_timeline.py` | Narasi per baris + pemendekan jeda → mix.wav + timeline.json. |
| `standup_timeline.py` | Seperti di atas, plus tawa dengan onset tepat di ujung punchline. v2: jeda sebelum punchline, tawa ditimpa + diredam, kekeh tersebar, room tone, pantulan ruangan, laporan ritme (`--config` untuk uji). |
| `lirik_timeline.py` | Seri Lirik: waktu baris lagu (manual atau dari LRCLIB, hanya waktu + jumlah kata) + teks dari `lirik.txt` yang diisi pengguna → `src/lirik.json` dengan Outro C. Membuat template `lirik.txt` berisi patokan waktu dan memperingatkan jumlah baris/kata yang tidak cocok. |
| `laugh_library.py` | Pembaca pustaka tawa (v2 lalu v1) dan deteksi onset (dipakai standup_timeline). |
| `voice_stats.cjs` | Ukur ekspresi take narasi: variasi dan rentang nada, puncak nada, rentang keras-pelan, lantai derau (ambang relatif per take; pembanding antar-take). |
| `voice_library.py` | Cari kandidat suara di pustaka ElevenLabs (`--gender male --age young`, bahasa id) atau daftar My Voices (`--mine`). Hanya membaca. Uji dengar kandidat: `scripts/elevenlabs_api.py --voice-id <id>` (audisi; profil suara tidak berubah). |
| `make_room_ir.py`, `make_room_tone.py` | Buat pantulan ruangan kecil dan dengung ruangan untuk seri Open Mic (deterministik, tanpa biaya). |
| `mix_sfx.py` | Campur efek `shared/audio/sfx-lokal/v1` ke video tanpa render ulang. |
| `render-thumb.cjs` | Thumbnail PNG 9:16 + potongan 4:5 dan 3:4 + lock. `--only` = satu PNG (lembar contoh). |
| `check-shared.cjs` | Uji portabilitas semua kode di `shared/`, `--locks` cek file shared yang sudah dipakai video tidak berubah, `--write` perbarui catalog.json dan catalog.html. |
| `runtime.cjs`, `runtime.py` | Lokasi Node, ffmpeg, Chrome, Playwright, node_modules. |
| `studio/` | Dashboard lokal Studio Less.: grid video, backsound, unggah lewat tebar, analisa + saran Claude Code. Lihat bagian "Studio" di bawah. |
| `backsound/` | Tambah lagu ke video yang sudah disetujui: web (tab Backsound di Studio, atau `server.cjs` sendiri) + CLI resep (`backsound.cjs`). Lihat bagian "Backsound" di bawah. |

## Backsound: lagu di video yang sudah disetujui (8 Nov 2026)
Pengguna memilih lagu dan bagiannya sendiri. Arahan: `references/arahan-pengguna.md` bagian Audio ("Backsound per video"). Aturan umum "tanpa musik latar" tetap berlaku; backsound hanya untuk video yang dipilih atau diminta pengguna.

**Web (untuk pengguna):** tab Backsound di dashboard Studio (bagian "Studio" di bawah). Bisa juga sendiri: `node tools/backsound/server.cjs` → http://localhost:4870.
1. Pilih video. Daftarnya diambil dari `approved` dan `active` (yang berstatus "disetujui") di `ACTIVE-WORKSPACE.json`, ditambah `siap-unggah/*/video.mp4`. File yang sama di dua tempat hanya muncul sekali.
2. Masukkan lagu dari file sendiri. **Ambil dari Downloads** memindahkan file ke pustaka: audio dipindah dan hilang dari Downloads, sedangkan video diambil suaranya lalu file videonya dibuang ke Tong Sampah (bisa dipulihkan). Seret ke halaman / "pilih file" hanya menyalin, karena browser tidak tahu letak file aslinya. Di daftar lagu, 🎬 = suara dari file video, 🎵 = file audio. Bisa file audio (mp3, m4a, wav, flac, ogg) atau video (mp4, mov), yang diambil hanya suaranya. Judul dan penyanyi terbaca dari tag file dan bisa diubah.
3. Pilih bagian lagu dengan menggeser kotak di gelombang (tombol ±1 dan ±0,1 dtk untuk geser halus).
4. Atur suara video dan suara lagu (dB), fade in, fade out, dan "kecilkan lagu saat ada narasi" (turun 8 dB).
5. Klik Putar untuk pratinjau sinkron, lalu "Buat video baru".

**Hasil (selalu file baru, file asli tidak pernah ditimpa):** `<proyek>/04-Hasil/backsound/<nama>.mp4`, plus `<nama>.resep.json` (resep + hasil cek level) dan `<nama>.kredit.md` (baris caption + blok `backsound` untuk `unggah.json`). Kalau nama sudah ada, hasil baru diberi akhiran `-2`, `-3`, dan seterusnya. Video tanpa folder proyek → `output/backsound/`. Gambar disalin apa adanya (`-c:v copy`); hanya audio yang diolah.

**CLI (untuk agen, "kamu suruh"):**
| Perintah | Fungsi |
|---|---|
| `node tools/backsound/backsound.cjs daftar` | video disetujui, lagu di pustaka, status sumber |
| `... impor <file> [--judul X --penyanyi Y]` | salin file lagu milik pengguna ke pustaka |
| `... buat --video <file/kata> --lagu <file/kata> [--mulai 1:02.5] [--vol-lagu -16] [--vol-video 0] [--fade-in 1] [--fade-out 2.5] [--duck 8 \| --tanpa-duck] [--masuk T] [--durasi T] [--nama N] [--render]` | buat resep (dan render) |
| `... render <resep.json> [--deteksi-ulang]` | jalankan ulang resep → file baru; hasilnya identik setiap kali (audio MD5 sama) |
| `... cek <video>` | ukur level (ebur128 + volumedetect) |
| `... cari <openverse\|openverse-efek\|jamendo\|freesound\|itunes\|deezer> <kata>` dan `... ambil <sumber> <id>` | cadangan: cari musik CC dan unduh ke pustaka (tidak tampil di web) |

**Cara kerja mix:** lagu dipotong dari `mulai_di_lagu`, fade in/out linear, volume lagu, lalu ducking. Narasi dideteksi dengan `silencedetect` (−38 dB, jeda ≥0,35 dtk). Jeda di bawah 0,8 dtk (`gabung_jeda`) dianggap masih narasi supaya lagu tidak naik-turun di setiap jeda napas; ramp turun 200 ms sebelum narasi dan naik 500 ms sesudahnya. Rumusnya ada di `backsound/gain.js` dan dipakai bersama oleh pratinjau browser dan ekspresi ffmpeg. Setelah dicampur: limiter −2 dBFS (latensi dikompensasi, sinkron dicek sampai sampel), lalu `loudness.py --fix` ke −14 LUFS / −1 dBTP. Laporan level mencetak kenyaringan hasil dan selisih lagu terhadap audio video (LU).

**Pustaka lagu:** `shared/audio/backsound/<sumber>/<judul>-<sha8>/` berisi `lagu.*`, `lisensi.json`, dan README (sumber, lisensi, tanggal). `impor/` diabaikan git karena bisa berisi lagu berhak cipta; resep mencatat sha256 lagu, jadi impor ulang file yang sama sebelum menjalankan resep di mesin lain. Hasil mix `*.mp4` di `04-Hasil/backsound/` juga diabaikan git (bisa dibuat ulang dari resep).

**Hak cipta dan lisensi:**
- Tidak ada pengunduh YouTube/TikTok/Instagram, karena melanggar ToS platform dan hak cipta. Lagu terkenal masuk lewat file milik pengguna.
- Lagu berhak cipta yang ditempel di file hampir pasti kena klaim Content ID di YouTube dan bisa dibisukan di IG/TikTok/FB. Web dan file kredit selalu memperingatkan ini dan mencatat titik mulai lagu untuk jalur aman (pasang lagu yang sama dari pustaka musik platform).
- Sumber CC (cadangan CLI): Openverse tanpa key, hanya CC0, PDM, BY, dan BY-SA. Jamendo butuh `JAMENDO_CLIENT_ID` dan Freesound butuh `FREESOUND_API_KEY` di `.env`, keduanya daftar gratis oleh pengguna dan belum diuji karena key belum ada. Lisensi ND/sampling ditolak, NC diberi peringatan (akun bisa dimonetisasi), BY/BY-SA wajib kredit di caption.
- iTunes/Deezer hanya untuk data lagu dan pratinjau 30 dtk; tidak bisa diunduh atau dicampur.
- Video seri Lirik boleh di-mix (pilihan pengguna 8 Nov 2026) dengan peringatan: unggahan resmi tetap memasang lagu dari pustaka platform (`references/kemasan.md` "Seri Lirik").

## Studio: dashboard lokal (8 Nov 2026)

Cara lain: `node tools/studio/server.cjs`, atau konfigurasi `studio` di `.claude/launch.json` (panel browser). Bawaan: hanya bisa diakses dari laptop ini.

**Buka di HP (Wi-Fi yang sama):** Beranda → **Buka di HP** → sakelar (hanya ada di laptop). Kalau menyala, server mendengar semua alamat IPv4 + IPv6 (`::`, bukan cuma 127.0.0.1), tapi hanya menerima perangkat dari **jaringan lokal** (IPv4 privat, IPv6 link-local/ULA, atau IPv6 dengan awalan /64 yang sama dengan laptop; alamat internet ditolak sebelum layar PIN). Panel menampilkan **QR https** dengan dua pilihan: **Buka sekarang** (`https://<IP Wi-Fi>:4870`, berubah tiap ganti Wi-Fi) dan **Ikon layar utama** (`https://<LocalHostName>.local:4870`, alamat tetap; butuh Wi-Fi yang mengizinkan nama lokal/mDNS), serta **PIN 6 angka**. Perangkat lain wajib memasukkan PIN (`/masuk`); sesi berlaku 30 hari (cookie HttpOnly), salah PIN 5x = diblokir 10 menit per alamat, **Ganti PIN** atau mematikan sakelar = semua HP keluar. Pengaturan akses hanya bisa diubah dari laptop (dari HP ditolak). PIN dan sesi di `reports/studio/akses-hp.json` (diabaikan git). Ikon layar utama: `/manifest.webmanifest` + `tools/studio/ikon/ikon-180/192/512.png` (Safari → Bagikan → Tambah ke Layar Utama). QR dibuat dengan CoreImage bawaan macOS (`tools/studio/qr.jxa.js`, tanpa unduhan) di `output/studio/qr/`. **iPhone:** Safari iOS 18.2+ mencoba https dulu, dan kalau setelan "Not Secure Connection Warning" menyala, tidak mau kembali ke http (error "couldn't establish a secure connection"). Karena itu, saat akses menyala, server melayani **http dan https di port yang sama** (byte pertama 0x16 = TLS → https) memakai sertifikat lokal buatan `openssl` bawaan macOS di `reports/studio/tls/` (diabaikan git; 825 hari; mencakup IP Wi-Fi saat ini, nama `.local`, localhost; dibuat ulang kalau IP berubah). Safari menampilkan "Koneksi ini tidak privat" sekali: Tampilkan Detail → kunjungi situs web ini. Selama akses menyala, server menjalankan `caffeinate -i -s -w <pid>` supaya laptop tidak tidur sendiri (layar boleh mati; menutup layar laptop tetap membuatnya tidur). Syarat: HP dan laptop di jaringan yang sama dan laptop menyala. Wi-Fi kantor/kafe/tamu sering memakai *client isolation* (perangkat tidak boleh saling sapa), jadi bisa gagal walau satu Wi-Fi; jalan keluarnya laptop disambungkan ke hotspot HP, lalu scan QR baru. **Pengaman unggah:**
- Push hanya dari tombol di layar Periksa. Server menolak tanpa konfirmasi itu.
