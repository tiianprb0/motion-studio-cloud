# Kampung Less. 2D (v1, 17 Nov 2026)
Satu dunia, beberapa tempat (arahan pengguna 17 Nov 2026, references/arahan-pengguna.md "Boleh satu dunia, tapi beberapa tempat"). Jalan kampung malam flat 2D berisi tempat dari web Less. (urut x dunia): gapura "Kampung Less." + papan less.benaya.id (±380), Kos Naya (±1080), Pos Keresahan (±1880, kotak TITIP di 1640, tali lampion `taliPos(u)`), Ruang Baca (±2760), Meja Gambar Yan (±3640, tokoh duduk di `TEMPAT_KL.meja.kursi`, meja digambar di depannya), Lahan Cerita (±4560). Trotoar (kaki tokoh) y 1250, 1 m = 230 px, tokoh skala 1,15. Kamera Kam2D seperti lokasi flat lain; pindah tempat = kamera menyusuri jalan atau tokoh berjalan (`langkah()`).
Slot: `isi`, `lampion`, `jendelaLampion` (lampion menyala di jendela rumah latar), `jendelaNaya`, `layarRumah`, `hujan`, `gelap`, `kabur`. Contoh: `contoh/ContohKampung.png`. Hanya malam di v1; versi siang/sore = v2.
