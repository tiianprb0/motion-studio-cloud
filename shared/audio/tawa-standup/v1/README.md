# Pustaka tawa Open Mic v1 (7 Nov 2026)
12 klip ElevenLabs Sound Effects, dibuat sekali atas izin pengguna. Dipakai ulang untuk semua episode stand-up; jangan generate lagi.
Semua klip langsung mulai (hening di kepala ≤ 0,3 dtk; build-audio memangkasnya otomatis).
| Klip | Durasi | Kegunaan |
|---|---|---|
| kekeh-kecil-1, kekeh-kecil-2 | 2,5 dtk | senyum/kekeh sebelum punchline lanjutan |
| tawa-sedang-1, tawa-sedang-2 | 3,5 dtk | punchline biasa, campur |
| tawa-sedang-cewek / -cowok | 3,5 dtk | variasi warna suara |
| tawa-sinis | 3,5 dtk | "ooh" lalu tawa, untuk lelucon gelap |
| tawa-besar-1, tawa-besar-2 | 5 dtk | punchline terkuat |
| tawa-tepuk | 5,5 dtk | tawa sambil tepuk tangan (applause break) |
| tepuk-singkat | 3 dtk | tepuk tangan pendek |
| tepuk-penutup | 7 dtk | akhir set |
Contoh level (puncak): kekeh -12…-15 dB, sedang -6…-13 dB, besar -9…-10 dB; turunkan gain supaya puncak sekitar -14 dB di bawah narasi.
